Projet AGRITECH

Smart Irrigation and Pest Detection System

Tutoriel d'installation et de configuration complet

📑 Navigation Rapide

📌 Présentation du Projet

Ce projet vise à développer un système d'irrigation intelligent qui automatise l'arrosage en fonction de l'humidité du sol, tout en intégrant la détection des nuisibles à l'aide d'une caméra et de l'intelligence artificielle.

Le système est piloté par un microcontrôleur ESP32 et offre un suivi en temps réel via une application desktop développée avec Qt.

🚀 Fonctionnalités Principales

💧 Irrigation Automatisée

Ajustement de l'arrosage selon les capteurs d'humidité du sol

🐛 Détection des Nuisibles

Utilisation d'une caméra et d'un modèle IA entraîné

📡 Connectivité ESP32

Transmission des données via protocole MQTT

📊 Dashboard Utilisateur

Visualisation et contrôle en temps réel

🔔 Notifications

Alertes en cas de détection de nuisibles ou d'anomalies

🎓 Aspect Pédagogique

Apprentissage interactif pour les enfants

🔍 Comment trouver Qt 6.8.2 si elle n'est pas listée

  1. Ouvrir Qt Maintenance Tool (installé avec Qt)

  3. Dans la section Qt → Archive ou Archive

  • MinGW 64-bit (compilateur pour Windows)
  • Qt Charts (pour les graphiques)
  • Qt MQTT (protocole de communication)
  • Qt Multimedia (gestion caméra/vidéo)
  • Qt Widgets (interface utilisateur)
  • Qt Network (communication réseau)
  • Qt Quick (interface moderne)

🐍 Configuration Python

📄 Fichier Python requis

Vous devez créer le fichier pest_detection.py dans le dossier racine du projet.

🤖 Modèle IA

⚠️ Important
Le fichier best_agritech.pt (modèle IA entraîné) doit être placé dans le même dossier que pest_detection.py. Cette disposition est obligatoire car le script Python utilise un chemin relatif.

⚙️ Configuration dans le fichier .pro

Vous devez modifier les chemins Python dans votre fichier .pro selon votre installation :

INCLUDEPATH += C:/Users/VOTRE_NOM_UTILISATEUR/AppData/Local/Programs/Python/Python312/include
LIBS += -LC:/Users/VOTRE_NOM_UTILISATEUR/AppData/Local/Programs/Python/Python312/libs -lpython312
🔍 Comment trouver votre chemin Python
  1. Ouvrir un terminal CMD
  2. Taper : python --version (vérifier la version)
  3. Taper : where python (affiche le chemin)
  4. Utiliser ce chemin dans le fichier .pro

📍 Modification du chemin du modèle dans dashboardwindow.cpp

Dans le fichier dashboardwindow.cpp (environ ligne 80), modifiez le chemin vers le modèle IA :

QString modelPath = "C:/chemin/vers/votre/projet/application/best_agritech.pt";
⚠️ Attention au format
Utilisez des slashes / et non des backslashes \ dans les chemins, même sous Windows. Qt gère automatiquement la conversion.

🚀 Lancement du script Python

Pour tester la détection de nuisibles :

cd chemin/vers/votre/projet
.\venv\Scripts\activate
python pest_detection.py best_agritech.pt

📡 Configuration MQTT avec Mosquitto

🔹 Installation du Broker Mosquitto

Tutoriel vidéo complet : https://youtu.be/4ZEPPQLY5o4

💡 Qu'est-ce que MQTT ?
MQTT est un protocole de messagerie léger utilisé pour la communication entre l'ESP32 et l'application Qt. Le broker Mosquitto agit comme un serveur central qui reçoit et distribue les messages.

💻 Commandes d'accès à Mosquitto (CMD Administrateur)

cd ..
cd "Program Files"
cd mosquitto

🔒 Autorisation du port MQTT (1883)

Méthode 1 : Interface graphique

  1. Appuyer sur Win + R
  2. Taper wf.msc et appuyer sur Entrée
  3. Cliquer sur Inbound Rules (Règles entrantes)
  4. Cliquer sur New Rule (Nouvelle règle)
  5. Sélectionner Port → Suivant
  6. Sélectionner TCP
  7. Entrer le port : 1883
  8. Sélectionner Allow the connection
  9. Cocher tous les profils (Domain, Private, Public)
  10. Nommer la règle : MQTT Broker

Méthode 2 : Ligne de commande (CMD Administrateur)

netsh advfirewall firewall add rule name="MQTT Broker" dir=in action=allow protocol=TCP localport=1883

⚙️ Configuration du fichier mosquitto.conf

Ouvrir le fichier mosquitto.conf (dans C:\Program Files\mosquitto\) et ajouter :

listener 1883 0.0.0.0
allow_anonymous true
protocol mqtt
⚠️ Sécurité
La configuration allow_anonymous true est pratique pour le développement mais n'est PAS recommandée en production. Pour un usage réel, configurez des identifiants MQTT.

🔄 Redémarrage du service Mosquitto

net stop mosquitto
net start mosquitto
✅ Vérification
Pour vérifier que Mosquitto fonctionne : netstat -an | findstr 1883
Vous devriez voir une ligne avec 0.0.0.0:1883

🌐 Configuration de l'Adresse IP et du Réseau

⚠️ Très Important - Configuration Réseau
Le choix du réseau est crucial pour le bon fonctionnement du système MQTT.

✅ Réseaux Recommandés

  • Hotspot Android - Solution idéale et testée
  • Réseau Wi-Fi domestique - Fonctionne bien
  • Box Internet personnelle - Compatible

❌ Réseaux à Éviter

Ne PAS utiliser :
  • Réseaux universitaires (ENSAO, etc.)
  • Réseaux d'entreprise
  • Réseaux publics avec restrictions
Raison : Ces réseaux bloquent généralement le port 1883 (MQTT) pour des raisons de sécurité.

🔍 Comment trouver votre adresse IP

Sous Windows :

ipconfig

Chercher Adresse IPv4 dans la section de votre connexion active (Wi-Fi ou Ethernet).

Format habituel : 192.168.x.x ou 10.x.x.x

📝 Où modifier l'adresse IP

Deux emplacements à modifier avec la MÊME adresse IP :
  1. Dans le code Arduino (ESP32) 
    const char* mqtt_server = "192.168.x.x";  // Votre IP locale
  2. Dans valuemqtt.cpp (ligne ~253) 
    client->connectToHost("192.168.x.x", 1883);  // Même IP
💡 Astuce Hotspot Android
Si vous utilisez un hotspot Android :
  1. Activer le hotspot sur votre téléphone Android
  2. Connecter votre ordinateur ET votre ESP32 au hotspot
  3. Trouver l'IP de votre ordinateur : ipconfig
  4. L'adresse commence généralement par 192.168.43.x
⚠️ Note importante
Les hotspots iOS ne sont pas recommandés pour ce projet car ils ne fonctionnent pas correctement avec le protocole MQTT. Privilégiez un hotspot Android ou un réseau Wi-Fi domestique.

🆘 En Cas de Problème

Problèmes fréquents et solutions :
  • Erreur de compilation Qt : Vérifier que Qt 6.8.2 est bien installé
  • Module MQTT introuvable : Réinstaller Qt MQTT via Maintenance Tool
  • Impossible de se connecter à MQTT : Vérifier firewall et adresse IP
  • ESP32 ne se connecte pas : Vérifier SSID/mot de passe Wi-Fi et adresse IP
  • Modèle IA non chargé : Vérifier le chemin absolu vers best_agritech.pt
  • Python non reconnu : Vérifier les chemins dans le fichier .pro
